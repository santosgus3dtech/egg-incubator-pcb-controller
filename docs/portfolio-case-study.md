# Portfolio Case Study: Incubator Controller PCB

## Problem

An incubator controller needs reliable 12 V input handling, stable 5 V regulation, sensor interfaces, relay control, and serviceable test points.

## Solution

The rev 3.7 design consolidates the control schematic around Arduino UNO R4 WiFi and replaces a module-style regulator with an AP63205 buck design that can be reviewed, sourced, and laid out deliberately.

## Highlights

- Datasheet-backed buck converter section.
- BOM with candidate parts.
- Jumpers for staged bring-up and isolation.
- RTC, encoder, water-level sensor, buzzer, environmental I2C sensor, relay, fan rail, and test points.
- Public repo contains curated release files instead of raw local EasyEDA backups.

## Recruiter signal

This project shows hardware reasoning and engineering communication, not just code. It is useful evidence for embedded, maker, IoT, and automation roles.
